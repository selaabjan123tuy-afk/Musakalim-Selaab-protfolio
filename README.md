# Musakalim selaab

React + Vite + Tailwind CSS v4 + Motion.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Customize

- Replace the portrait URL in `src/components/Hero.jsx`.
- Replace project images and links in `src/components/Projects.jsx`.
- Replace contact information in `src/components/Contact.jsx`.
- Change experience, skills and statistics in their respective components.

The layout is responsive and uses `motion/react` for entrance, hover and progress animations.
